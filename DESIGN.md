# SISTEMA DE DISEÑO // AXIOMA-CORE (DARK LUXE & CINEMÁTICA IMAX)

## 🌌 1. Paleta de Colores Fundacional (Alto Contraste)
- **Canvas / Fondo:** `#030305` (Negro abisal cinemático, profundidad IMAX)
- **Superficie / Cartas:** `#0A0B0E` (Obsidiana con tinte frío)
- **Superficie Elevada:** `#14161D` (Borde y contenedores modulares)
- **Texto Principal:** `#F5F5F7` (Blanco perla frío, máxima legibilidad)
- **Texto Secundario:** `#8E8E93` (Gris neutro de precisión)
- **Acento Estelar:** `#E2B872` (Oro cálido estelar, jerarquía táctica)
- **Cian Cósmico:** `#00F2FE` (Neón de telemetría y estado de enlace)
- **Borde Sutil:** `rgba(245, 245, 247, 0.08)` (Delimitación sin ruido visual)

## 🎛️ 2. Tipografía & Escala
- **Display / Titulares:** San Francisco / Inter / Sans-serif neutro con kerning expandido (`tracking-wider` / `tracking-widest`).
- **Datos & Telemetría:** Monospace (`ui-monospace`, `SFMono-Regular`, `Menlo`) para valores y puertos.
- **Micro-Copy:** 10px - 12px uppercase con opacidad controlada (60% - 80%).

## ⚡ 3. Atmósfera Visual (Neurovisceral IMAX)
- **Glow & Resonancia:** Destellos sutiles `box-shadow: 0 0 24px -4px rgba(0, 242, 254, 0.18)`.
- **Minimalismo Radical:** Cero saturación de elementos. Espacios de respiración generosos.
- **Indicadores de Estado:** Pulsos lentos (2.5s) que emulan biorritmos y sincronización neuronal.
